## Beta notes

This is an early beta distributed as a pre-release. Install only if you trust the publisher. Review [the privacy notice](PRIVACY.md) before use.

The optional PC learning sync currently uses plain HTTP on a local network. Only use it on a trusted private Wi-Fi network. Voice typing depends on the speech-recognition provider installed on your device.
